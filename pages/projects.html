WriteEZ is a dictation web application used to help make writing online papers a little easier for people with disabilites that make typing hard or simply people who just prefer not to type.

WriteEZ has all the privacy, accessibility, and easy-to-use UI you will ever need for typing any form of documents online! With all the features being local on your machine your data is guaranteed to be safe! (since it never leaves your machine)

Along with privacy this web app can be fully utilized without any connection to the internet!

This web app can be fully traveresed with either mouse clicks or keyboard commands, (If you are unsure how to use the keyboard commands simply press the 'h' key to open the fully audio help menu!)


This app has it all! With the AI integration you can get it all done in one place instead of having to visit multiple sites! Just simply upload an audio recording and AI will parse out the recording and fully create and format a paper for you!

If writing a paper is not what you are looking for this app has many other uses. Stressed out with all the stuff you need to get done? Take a recording describing all the things you need to get done and have AI create a to-do list for you! If you need some time to think in the audio recording that is ok! AI will only keep the important information ;)

A LoRa and BLE-based system for safety and proximity awareness in cave exploration.

BatSignal is a LoRa-based proximity and communication system designed to help keep a team of spelunkers safe underground. It uses short-range wireless communication and proximity detection via LoRa (Long Range) radios and Bluetooth Low Energy (BLE).

Three LoRa nodes communicate with each other to measure RSSI (signal strength), which is used to estimate relative proximity between team members.

With built-in alert systems and emergency button functionality, this project enhances team safety by warning users when a memebr is out of range or when an emergency signal is triggered.

A companion iOS app connects via BLE to one LoRa node and displays real-time proximity data visually.
